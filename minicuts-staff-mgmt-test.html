☁️ Supabase Sync
Supabase is the source of truth. Every time this page loads, it pulls the latest data from the cloud and overwrites what's on this device. Every save is pushed to Supabase immediately and auto-retried if the connection drops — watch the ☁️ status badge (top right) to confirm everything's synced. If you have old data that was only ever saved locally and never made it to the cloud, push it up once below.

🧹 Duplicate Staff Cleanup
If the same staff member got seeded independently on two devices before they ever synced, Supabase can end up with two rows for one person. This checks for that and, if found, safely reassigns every attendance/leave/overtime/roster/document record to the older copy before deleting the duplicate — nothing gets orphaned.
Click "Check" to scan for duplicate staff.
📁 Document Storage
Staff documents (visas, Emirates IDs, passports etc) now upload straight to a private Supabase Storage bucket instead of being embedded as text in the database. Older documents saved before this change are still stored as base64 text — this moves them over, then clears the old bloated data from the table. Requires the staff-documents bucket to already exist (see setup instructions).
Click "Check" to see how many documents still need migrating.
